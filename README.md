# Search Engines for Pentesters

A curated collection of tools for reconnaissance, OSINT, and attack surface discovery.

## Server Reconnaissance
- [Shodan](https://shodan.io) - Find exposed devices on the internet
- [Onyphe](https://onyphe.io) - Cyber threat intelligence from global sensors
- [Censys](https://censys.io) - Deep visibility into internet-facing assets
- [IVRE](https://ivre.rocks) - Network mapper & passive reconnaissance powerhouse

## Dorking
- [Google](https://google.com) - The original dorking tool (with the right queries)

## WiFi Networks
- [WiGLE](https://wigle.net) - Map and track global WiFi networks

## Threat Intelligence
- [BinaryEdge](https://app.binaryedge.io) - Scan and analyze internet-facing assets
- [GreyNoise](https://viz.greynoise.io) - Filter out background noise from real threats
- [FOFA](https://fofa.info) - Search across global cyberspace data
- [ZoomEye](https://zoomeye.org) - Hacker's search engine for devices & services
- [LeakIX](https://leakix.net) - Discover leaks, breaches, and exposed services
- [URLScan](https://urlscan.io) - Analyze and track web content & threats
- [SOCRadar](https://socradar.io) - External attack surface & threat monitoring
- [Pulsedive](https://pulsedive.com) - Dive into threat intelligence feeds

## OSINT & Emails
- [Hunter](https://hunter.io) - Find emails linked to any domain
- [IntelX](https://intelx.io) - Search leaked data, domains, emails & more

## Attack Surface Discovery
- [Netlas](https://app.netlas.io) - Visualize and explore attack surfaces
- [FullHunt](https://fullhunt.io) - Monitor assets and misconfigurations
- [BinaryEdge](https://binaryedge.io) - Threat detection meets asset intelligence

## Code & Web Search
- [Grep.app](https://grep.app) - Instantly search across open-source code
- [Searchcode](https://searchcode.com) - Index of code from thousands of projects
- [PublicWWW](https://publicwww.com) - Search source code by keyword or snippet

## Certificates
- [crt.sh](https://crt.sh) - Look up SSL/TLS certs for domains

## Vulnerabilities
- [Vulners](https://vulners.com) - Centralized vulnerability search engine

## Usage Guidelines
- Always perform ethical reconnaissance and pentesting
- Obtain proper authorization before testing any system
- Follow responsible disclosure practices for any vulnerabilities
- Be aware of legal implications across different jurisdictions
